One word to erase from the dictionary forever — `phlegm` — written by a program to `/output/entry.txt` for make.fun's "The Word You'd Delete From the Dictionary" bounty ($2 in USDC). The whole room goes "ew" the moment it is said; its sound is the joke, and the gap it leaves is perfect: the stuff stays, now unnameable.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
